# Aziz BM — editable portfolio source

Source for https://azizverse.github.io/.

Run `npm ci`, then `npm run dev` for local development.
Run `npm run lint` and `npm run build` before publication.

`src/content.ts` holds public copy, projects, contact links, and the production URL.
`src/App.tsx` holds components and sharing interactions.
`public/assets/abm-logo.svg` is the refined logo.

Deployment uses the static build in `dist/`. See the repository-root README for GitHub Pages publication instructions. The public content intentionally keeps venture introductions brief.
